# 论文材料交接与指标表达修复

外部实验导入后，原写作器只拿到结果文件和路径说明，真实源码没有进入写作上下文；主图也可能直接展示负 AP 优化目标。

本次修复：

- 复核已登记的外部实验时，保存小型源码、执行配置及逐文件哈希。旧项目可通过已登记目录补读。快照明确属于导入时的材料，不冒充训练时不可变的源码履历；不复制权重、数据集或大型预测张量。
- 分析、写作、审阅和导出共用指标说明，区分优化目标与论文指标、实测场景与损失窗口、声明的验证规模以及未知的精度/召回率阈值口径。相同场景数不证明属于官方测试集，不同场景列表不自动作为同一配对比较。
- 仅在实测 AP 与负优化目标的对应关系已核对时，自动生成正 AP 主图；不对通用负数指标取绝对值，不猜未记录的 IoU 范围，也不虚构误差棒。恢复第25阶段也能纠正旧主图。
- 修复图片说明中的嵌套方括号、分号组合引用、空行隔开的表题，以及普通组件表被自动叫作消融的问题；检查超出实际图片数量的图号引用。
- 质量分数和阈值分别标明十分制，避免把“分数/阈值”误当作评分满分。

新增12项回归检查，本地与服务器隔离环境各完成115项定向检查。使用真实GSF导入记录检查核心源码可读、2/312场景范围以及实测正AP图，不调用新训练或论文生成接口。

这些改动减少论文漏写、误写和超出证据的表述，不替代完整验证、消融、边界分析或独立权重推理。
